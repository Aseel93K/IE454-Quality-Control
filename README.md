# IE454 Quality Control: interactive labs

Companion websites for IE454 Quality Control (Dr. Aseel Khanfar, Yarmouk University), built on Montgomery, *Introduction to Statistical Quality Control*, 8th ed.

| Page | Folder |
|---|---|
| All chapters (start page) | `/` |
| Chapter 1: Quality Improvement | `ch01/` |
| Chapter 2: The DMAIC Process | `ch02/` |
| Chapter 3: Modeling Process Quality | `ch03/` |
| Chapter 5: Methods and Philosophy of SPC | `ch05/` |
| Chapter 6: Control Charts for Variables | `ch06/` |
| Chapter 7: Control Charts for Attributes | `ch07/` |
| Chapter 8: Process Capability | `ch08/` |
| IE454 Class Lab (in-class data entry) | `lab/` |

Every page is a single self-contained HTML file. Activity anchors work as before, for example `ch05/#arl`.

On GitHub Pages the Class Lab saves entered data in the browser of the computer you type on.
